# Luna 框架使用指南

## 1. 项目简介

Luna 是一个基于 Java Agent 技术的动态字节码注入框架，用于实现非侵入式的应用监控和日志注入。通过 ASM 字节码操作，Luna 可以在运行时动态修改类的字节码，实现方法级和行号级的日志注入，无需修改源代码。

## 2. 核心功能

- **方法级日志注入**：支持在方法进入、退出和环绕时注入日志
- **行号级日志注入**：支持在指定行前后注入日志
- **表达式引擎**：支持变量引用、函数调用和复杂条件表达式
- **Web UI 配置**：提供可视化的规则配置界面
- **规则持久化**：支持规则的保存和加载
- **性能优化**：实现缓存机制，减少性能开销

## 3. 快速开始

### 3.1 构建项目

```bash
mvn clean package
```

### 3.2 启动 Agent

使用以下命令启动目标应用，并加载 Luna Agent：

```bash
java -javaagent:luna-agent-1.0.0.jar -jar your-application.jar
```

### 3.3 访问 Web UI

启动应用后，访问 `http://localhost:8080` 即可进入 Luna 的 Web UI 界面。

## 4. 配置规则

### 4.1 添加规则

1. 进入 Web UI 界面，点击 "规则配置" 标签
2. 点击 "添加规则" 按钮
3. 填写规则信息：
   - 目标类：要注入的类的全限定名
   - 目标方法：要注入的方法名
   - 注入类型：选择注入类型（方法进入、方法退出、方法环绕、行前、行后）
   - 行号：如果选择行前或行后注入，需要填写目标行号
   - 条件表达式：可选，用于控制注入的条件
   - 日志内容：要注入的日志内容
4. 点击 "保存" 按钮

### 4.2 编辑规则

1. 在规则列表中找到要编辑的规则
2. 点击 "编辑" 按钮
3. 修改规则信息
4. 点击 "保存" 按钮

### 4.3 删除规则

1. 在规则列表中找到要删除的规则
2. 点击 "删除" 按钮
3. 确认删除操作

## 5. 表达式引擎

Luna 的表达式引擎支持以下特性：

- **常量**：数字、字符串、布尔值
- **变量**：可以引用方法参数、局部变量等
- **操作符**：算术操作符（+、-、*、/）、比较操作符（==、!=、>、<、>=、<=）、逻辑操作符（&&、||、!）
- **函数**：支持内置函数，如 length()、toLowerCase() 等

### 5.1 表达式示例

```
// 常量表达式
42
"Hello, World!"
true

// 变量表达式
x + y
user.name

// 函数调用
length("Hello")
toLowerCase("HELLO")

// 复杂表达式
(x + y) * 2 > 20 && length("test") == 4
```

## 6. 性能优化

Luna 实现了以下性能优化措施：

- **字节码缓存**：缓存转换后的字节码，避免重复转换
- **分析结果缓存**：缓存类的分析结果，避免重复分析
- **高效的字节码操作**：使用 ASM 进行高效的字节码操作

## 7. 示例应用

### 7.1 方法级日志注入示例

**规则配置**：
- 目标类：`com.example.service.UserService`
- 目标方法：`login`
- 注入类型：`方法环绕`
- 日志内容：`"User login: " + username`

**效果**：当 `UserService.login()` 方法执行时，会在方法进入和退出时记录日志。

### 7.2 行号级日志注入示例

**规则配置**：
- 目标类：`com.example.controller.UserController`
- 目标方法：`getUser`
- 注入类型：`行前`
- 行号：`42`
- 日志内容：`"Getting user with id: " + id`

**效果**：当执行到 `UserController.getUser()` 方法的第 42 行时，会在该行前记录日志。

## 8. 常见问题

### 8.1 注入失败

- 检查目标类和方法是否存在
- 检查注入类型是否正确
- 检查条件表达式是否合法

### 8.2 性能问题

- 避免在高频方法上进行注入
- 使用条件表达式控制注入的范围
- 定期清理缓存

### 8.3 日志不显示

- 检查日志配置是否正确
- 检查注入的日志级别是否正确
- 检查目标方法是否被执行

## 9. 技术架构

Luna 采用以下技术架构：

- **Java Agent**：用于在运行时加载和转换类
- **ASM**：用于字节码操作
- **Jetty**：用于提供 Web UI 界面
- **Vue 3**：用于前端界面开发
- **FastJSON**：用于 JSON 序列化和反序列化
- **Log4j2**：用于日志记录
