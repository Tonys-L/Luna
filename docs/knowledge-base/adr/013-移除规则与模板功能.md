# ADR-013: 移除规则与模板功能

## 状态

Accepted

## 背景

规则（Rule）和模板（Template）功能引入了额外的复杂度，包括：

- **RuleManager、RulePersistenceService、RuleStatus、ClassNameMatcher**
- **TemplateEngine、TemplateService、TemplateRegistry、RuleTemplate、BuiltinTemplates**
- **InjectionRuleConverter、AbstractRuleConverter、MethodRuleConverter、LineRuleConverter、RuleConverterRegistry**
- **RuleClassFileTransformer、RuleSuspensionManager**
- **RuleController、TemplateController**
- **PluginContext/PluginManager 中的 registerRuleConverter、registerTemplate、getTemplatesForPlugin**
- **PluginRegistrationRecord 中的 ruleConverters、templates 字段**

这些组件增加了大量系统复杂度，但实际使用率低。PersistentInjection 统一模型已能覆盖规则的核心需求（通配符匹配、持久化），模板功能可通过前端预设实现。

## 方案选项

### 选项 A: 保留规则/模板功能

维持现有的规则和模板功能，继续维护 RuleManager、TemplateEngine 等组件。

优点：
- 保留类首次加载时自动匹配注入的能力（RuleClassFileTransformer）
- 保留模板复用能力
- 无需迁移

缺点：
- 系统复杂度高，维护成本大
- 规则与注入的双轨概念增加理解成本
- RuleConverterRegistry 等组件使用率低，投入产出比差
- 与 PersistentInjection 统一模型存在概念重叠

### 选项 B: 删除规则/模板全链路

删除规则/模板相关的所有组件，包括：

- InjectionRule, RuleManager, RulePersistenceService, RuleStatus, ClassNameMatcher
- TemplateEngine, TemplateService, TemplateRegistry, RuleTemplate, BuiltinTemplates
- InjectionRuleConverter, AbstractRuleConverter, MethodRuleConverter, LineRuleConverter, RuleConverterRegistry
- RuleClassFileTransformer, RuleSuspensionManager
- RuleController, TemplateController
- PluginContext/PluginManager 中的 registerRuleConverter, registerTemplate, getTemplatesForPlugin
- PluginRegistrationRecord 中的 ruleConverters, templates 字段

优点：
- 简化注入模型，减少维护成本
- 消除规则与注入的双轨概念
- PersistentInjection 统一模型已能覆盖核心需求
- 模板功能可通过前端预设实现，无需后端支持

缺点：
- 失去类首次加载时自动匹配注入的能力，需通过 API 手动注入
- 已有的规则/模板配置需要迁移

## 决策

选择**选项 B：删除规则/模板全链路**。

规则/模板功能引入的复杂度远超其提供的价值。PersistentInjection 统一模型已能覆盖规则的核心需求（通配符匹配、持久化），模板功能可通过前端预设实现。失去类首次加载时自动匹配注入的能力是可接受的代价——用户可通过 API 手动注入，且这种显式方式更可控、更可预测。

## 影响

- 删除所有规则/模板相关类和接口
- PluginContext/PluginManager 中移除 registerRuleConverter、registerTemplate 等方法
- PluginRegistrationRecord 中移除 ruleConverters、templates 字段
- 注入模型统一为 PersistentInjection，无规则/模板概念
- 类首次加载时不再自动匹配注入，需通过 API 手动注入
