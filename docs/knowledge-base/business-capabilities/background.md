## 1.1 解决的问题

Luna 解决 Java 应用运行时诊断的核心痛点：

* **排障效率低**：传统方式依赖日志打印和重启，无法实时获取运行时状态
* **侵入性强**：APM 方案需要修改代码或引入 SDK，影响业务稳定性
* **观测粒度粗**：现有工具只能看到方法级耗时，无法深入到行号和变量级别
* **缺乏动态性**：问题出现时无法按需注入观测逻辑，必须预埋或重启

## 1.2 业务目标

| 目标 | 描述 | 优先级 |
|------|------|--------|
| 零侵入诊断 | 不修改业务代码、不重启应用即可注入观测逻辑 | P0 |
| 精准定位 | 支持方法级和行号级的精准注入 | P0 |
| 实时观测 | 注入后立即生效，数据实时推送 | P0 |
| 安全可控 | 注入代码受沙箱保护，不影响业务运行 | P0 |
| 插件化扩展 | 核心能力稳定，产品能力通过插件扩展 | P1 |
| 可视化协作 | 提供 Web UI 进行诊断操作和结果查看 | P1 |
