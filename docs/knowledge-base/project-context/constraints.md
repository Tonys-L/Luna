# 已知约束与性能基准

## 已知约束

### 人员约束

* 单人开发（Tony.L）
* 开源项目，社区贡献有限

### 技术约束

* 必须兼容 JDK 8+
* 必须零侵入（不能修改业务代码）
* 必须类隔离（Agent 依赖不能污染目标应用）
* ASM 字节码操作必须通过 Shade 重命名隔离
* 性能红线：单次插桩判定 < 0.1ms，CPU 抖动 < 2%

### 环境约束

* 目标应用可能运行在受限环境（无外网、容器化）
* 必须支持运行时 Attach（不重启目标 JVM）
* 反编译结果不是原始源码，行号可能漂移

---

## 性能基准

| 指标 | 基准值 | 验证方式 |
|------|--------|----------|
| 启动延迟 | < 450ms | Agent premain 到 ReadyGate 就绪 |
| 内存静态增量 | ~22MB | 堆内存对比（Agent 加载前后） |
| CPU 运行时抖动 | < 2% (100+TPS) | 压测对比 |
| 单次插桩判定 | < 0.1ms | 微基准测试 |
| 反编译速度 | 50Kb 类 < 100ms | 计时测量 |
| RingBuffer 吞吐 | > 10M ops/s | 微基准测试 |
