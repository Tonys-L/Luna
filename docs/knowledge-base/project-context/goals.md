# 项目目标、核心哲学与价值主张

## 项目目标

Luna 是基于 Java Agent 的运行时动态诊断基础设施（Runtime Observability & Diagnostics Infrastructure）。

解决的核心问题：

* **生产环境排障的"情报迷雾"**：传统排障依赖日志和重启，无法实时获取运行时状态
* **"决策时延"**：从发现问题到定位根因的周期过长
* **侵入性问题**：传统 APM 方案需要修改代码或重启应用

## 核心哲学

Luna 的核心定位是 **Runtime Observability & Diagnostics Infrastructure**。

核心判断标准："这个能力是在帮助理解 JVM，还是在替 JVM 执行业务？"

**Luna 是**：观测、诊断、验证、安全扰动运行时行为的工具。
**Luna 不是**：业务执行平台、业务逻辑扩展框架、持久业务状态管理器。

## 目标用户

* Java 后端开发人员 — 线上问题排查、复杂业务逻辑调试
* 运维/技术支持人员 — 快速定位生产环境故障，无需重启应用
* 技术培训/教学 — 演示代码执行流程和变量变化
* 开源项目维护者 — 复现并调试用户报告的复杂 Bug

## 核心价值主张

"在代码的阴影里，露娜为你标记真相。" — 零侵入、不重启、不发版的运行时深度诊断能力。
